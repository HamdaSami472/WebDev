Introduction

JavaScript is a cross-platform, object-oriented scripting language. It is a small and lightweight language. Inside a host environment (for example, a web browser), JavaScript can be connected to the objects of its environment to provide programmatic control over them.

JavaScript contains a standard library of objects, such as Array, Date, and Math, and a core set of language elements such as operators, control structures, and statements. Core JavaScript can be extended for a variety of purposes by supplementing it with additional objects.

Client-side JavaScript extends the core language by supplying objects to control a browser and its Document Object Model (DOM). For example, client-side extensions allow an application to place elements on an HTML form and respond to user events.

This guide assumes you have the following basic background:

  • Good working knowledge of HyperText Markup Language (HTML).
  • Some programming experience. If you are new to programming, try one of the tutorials linked on the MDN page.

JavaScript is a very forgiving language, but it helps to have some prior exposure to programming concepts like variables, loops, and functions.

JavaScript and Java

JavaScript and Java are similar in some ways but fundamentally different in others. The JavaScript language resembles Java but does not have Java's static typing or strong type checking.

JavaScript supports functions as first-class objects and is prototype-based, while Java is class-based. JavaScript is dynamically typed, whereas Java is statically typed.

Despite the naming, the two languages are distinct and designed for different use cases. JavaScript is primarily used in web browsers, while Java is a general-purpose language.

Hello world

To get started with writing JavaScript, open the developer console and write your first "Hello world" program:

console.log("Hello, World!");

You can also embed JavaScript in HTML using the <script> tag. This is the most common way to add interactivity to web pages.

  • Use console.log() for debugging.
  • Use alert() for simple pop-ups.
alert("Hello!");
Variables

Variables are containers for storing data values. In JavaScript, you can declare variables using var, let, or const.

Variable names can contain letters, digits, underscores, and dollar signs. They must begin with a letter, underscore, or dollar sign.

  • let – block-scoped, can be reassigned.
  • const – block-scoped, cannot be reassigned.
  • var – function-scoped, legacy.
let userName = "Alex";
Declaring variables

You can declare a variable in three ways:

  • Using var: var x = 5;
  • Using let: let y = 10;
  • Using const: const z = 15;

With let and const, the variable is limited to the block scope. With var, it is function-scoped.

let age = 25; const PI = 3.14;
Variable scope

Scope determines where variables are accessible. JavaScript has global scope, function scope, and block scope.

Global variables are declared outside any function. Local variables are declared inside a function or block.

  • Global: accessible everywhere.
  • Function: accessible only within the function.
  • Block: accessible only within the block ({ ... }).
if (true) { let blockVar = "visible only here"; }
Global variables

Global variables are declared outside any function or block. They are accessible from anywhere in the program.

In web browsers, global variables become properties of the window object. Use them sparingly to avoid name conflicts.

var globalVar = "I am global";

It's best practice to minimize the use of global variables to keep code clean and maintainable.

Constants

Constants are read-only variables that cannot be reassigned. They are declared using the const keyword.

Constants must be assigned a value when declared. They are block-scoped like let.

const TAX_RATE = 0.08;

Note that constants can still be mutable if they hold objects or arrays; you can modify the contents but not reassign the variable itself.

Data types

JavaScript has dynamic types. The language provides eight basic data types:

  • Number – integer or floating point.
  • String – sequence of characters.
  • Boolean – true or false.
  • Null – intentional absence of value.
  • Undefined – uninitialized variable.
  • Symbol – unique and immutable primitive.
  • BigInt – for large integers.
  • Object – collections of key-value pairs.
typeof null // "object" (historical)
if...else statement

The if...else statement executes a block of code if a specified condition is true, and another block if the condition is false.

if (score > 90) {
  console.log("Grade: A");
} else {
  console.log("Keep trying!");
}

You can also use else if to chain multiple conditions.

if (x > 0) { /* positive */ } else if (x < 0) { /* negative */ }
while statement

A while loop repeatedly executes a block of code as long as a condition is true.

let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}

Be careful to avoid infinite loops by ensuring the condition eventually becomes false.

let n = 0; while (n < 3) { n++; }
Function declarations

A function declaration defines a named function. Functions are reusable blocks of code.

function multiply(a, b) {
  return a * b;
}

Functions can be invoked with arguments. They can return values using the return statement.

  • Functions are first-class objects.
  • They can be assigned to variables.
const square = function(x) { return x * x; };
